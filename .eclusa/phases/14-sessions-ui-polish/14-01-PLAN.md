  2. Modify the `list_sessions` SQL query to LEFT JOIN through stage -> cascade -> intent to derive a title. Follow the exact pattern from `list_chat_sessions` in chat.py as reference:
     ```sql
     SELECT
       ws.id,
       ws.stage_ids[1] AS stage_id,
       ws.model,
       ws.state,
       COALESCE((ws.cost->>'estimated_usd')::numeric, 0) AS cost_estimated_usd,
       ws.created_at,
       COALESCE(
         NULLIF(c.narrative, ''),
         LEFT(i.raw, 120),
         ws.harness_type || ' session'
       ) AS title
     FROM work_session ws
     LEFT JOIN stage s ON s.id = ws.stage_ids[1]
     LEFT JOIN cascade c ON c.id = s.cascade_id
     LEFT JOIN intent i ON i.id = c.intent_id
     ORDER BY ws.created_at DESC, ws.id DESC
     LIMIT 100
     ```
     The title derivation priority: cascade.narrative (already set by chat_bridge), then intent.raw truncated to 120 chars, then fallback to harness_type + " session".
