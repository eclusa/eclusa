# Plan 07.1-01: Python Dependency Upgrade + Type Safety

## Objective

Upgrade all Python dependencies in pyproject.toml to latest stable versions. Add pyright config. Run ruff clean. Fix any import/type errors. Full pytest suite green after.

## Tasks

<task id="1" type="auto">
<action>
1. Run `uv add` to upgrade each pinned dep to latest:
   - `uv add "alembic>=1.18" "asyncpg>=0.31" "fastapi>=0.135" "psycopg[binary,pool]>=3.3" "pydantic-ai>=1.77" "sqlalchemy[asyncio]>=2.0"`
   - This lets uv resolve the latest compatible versions

2. Add pyright to dev deps: `uv add --group dev pyright`

3. Run `uv run ruff check . --fix` then `uv run ruff format .`

4. Run `uv run pyright --warnings 2>&1 | head -50` — note errors but don't block on them (many will be from untyped asyncpg)

5. Run `uv run pytest tests/ -x -q` — must pass
</action>
