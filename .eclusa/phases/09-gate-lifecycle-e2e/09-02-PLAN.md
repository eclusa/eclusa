API endpoints:
- GET /api/gates?state=blocked — returns GateItem[] with id, cascade_id, state, input, created_at, model_recommendation
- POST /api/gates/{gate_id}/resolve — body: { token: string, decision: string, actor_id: string }
- POST /api/auth/token — body: { secret: string } — returns { access_token: string }

Stage table columns used by GET /api/gates:
```sql
SELECT id, cascade_id, state, input, created_at, input->>'model_recommendation' AS model_recommendation
FROM stage WHERE type = 'gate'
```

Seed SQL (executed via psql):
```sql
-- Create test actor with resolve permissions
INSERT INTO actor (id, type, identity, permissions)
VALUES ('{ACTOR_UUID}', 'system', 'e2e-gate-ui-test', '{"resolve_gates":["*"],"view_costs":true}')
ON CONFLICT DO NOTHING;

-- Create intent
INSERT INTO intent (id, source, raw, created_by)
VALUES ('{INTENT_UUID}', 'api', 'E2E gate UI test', '{ACTOR_UUID}');

-- Create cascade
INSERT INTO cascade (id, intent_id, shape, state)
VALUES ('{CASCADE_UUID}', '{INTENT_UUID}', '{"test":"gate_ui"}', 'active');

-- Create gate stage in 'blocked' state (already surfaced)
INSERT INTO stage (id, cascade_id, type, state, depends_on, input)
VALUES (
  '{GATE_UUID}', '{CASCADE_UUID}', 'gate', 'blocked', '{}'::uuid[],
  '{"gate_type":"default","gate_description":"E2E UI test gate - please approve","model_recommendation":"approve"}'::jsonb
);

-- Create ledger entry for gate surfacing
INSERT INTO ledger_entry (id, stage_id, cascade_id, actor_id, type, content, schema_version)
VALUES (
  gen_random_uuid(), '{GATE_UUID}', '{CASCADE_UUID}', '{ACTOR_UUID}',
  'gate_surfaced',
  '{"stage_id":"{GATE_UUID}"}',
  '0002'
);
```

Generate deterministic UUIDs using a fixed prefix pattern for easy cleanup:
- ACTOR_UUID: `e2e00009-0000-0000-0000-000000000001`
- INTENT_UUID: `e2e00009-0000-0000-0000-000000000002`
- CASCADE_UUID: `e2e00009-0000-0000-0000-000000000003`
- GATE_UUID: `e2e00009-0000-0000-0000-000000000004`

**Cleanup (afterAll or test.afterEach):**

Run psql to delete in FK order:
1. `DELETE FROM ledger_entry WHERE cascade_id = '{CASCADE_UUID}'` (disable/enable immutability trigger)
2. `DELETE FROM stage WHERE cascade_id = '{CASCADE_UUID}'`
3. `DELETE FROM cascade WHERE id = '{CASCADE_UUID}'`
4. `DELETE FROM intent WHERE id = '{INTENT_UUID}'`
5. `DELETE FROM actor WHERE id = '{ACTOR_UUID}'`

Wrap ledger deletion with trigger disable/enable:

**Helper function: `runPsql(sql: string)`**

```typescript
import { execSync } from 'child_process'

const PSQL = 'psql postgresql://eclusa:eclusa@localhost:5432/eclusa -c'

function runPsql(sql: string) {
  execSync(`${PSQL} "${sql.replace(/"/g, '\\"')}"`, { stdio: 'pipe' })
}
```

Actually, use a multi-statement approach with `psql -f -` and pipe SQL via stdin for reliability with complex SQL. Use `execSync(cmd, { input: sql })` pattern.
