Create the ship stage handler that takes Generate stage output and produces a running application.

Purpose: This is the core implementation that closes the loop from "generated code text" to "running Docker container." Without this handler, the SCC pipeline produces code that sits in a database field and never runs.

Output: `executor/ship.py` containing `dispatch_scc_ship()` — a single handler that parses generated code into files, writes them to the object store, commits them to a per-cascade git repo, builds a Docker image, runs a container on a dynamic port, health-checks it, and creates artifact records for each step.

  <action>
Create `executor/ship.py` with these components:

1. **`parse_generated_code(text: str) -> list[tuple[str, str]]`** — Parse LLM-generated code text into individual files.
   - Split on triple-backtick fenced code blocks (```language ... ```)
   - For each block, extract filename from:
     a. First line comment like `# app.py` or `# filename: app.py` or `// filename: app.py` or `<!-- filename: index.html -->`
     b. If no filename comment, derive from language tag: python->main.py, html->index.html, css->style.css, javascript/js->app.js, dockerfile->Dockerfile
     c. If neither, use `file_{n}.txt`
   - If no fenced blocks found at all, return [("main.py", full_text)] as fallback
   - Strip the filename comment line from the content so it's not duplicated in the file

2. **`async def write_files_to_object_store(files: list[tuple[str, str]], conn, stage: dict, actor_id: str) -> list[tuple[str, str]]`**
   - Instantiate `LocalObjectStore()` (default path is fine)
   - For each (filename, content): call `store.put(content.encode("utf-8"))` to get the blake3 key
   - For each file, INSERT an artifact row:
     ```sql
     INSERT INTO artifact (id, intent_id, cascade_id, stage_id, type, external_ref, external_sys, payload)
     SELECT gen_random_uuid(), c.intent_id, $1::uuid, $2::uuid, 'file_created', $3, 'object_store',
            jsonb_build_object('filename', $4, 'blake3_key', $3, 'size_bytes', $5)
     FROM cascade c WHERE c.id = $1::uuid
     ```
   - Also INSERT a ledger_entry of type 'artifact_created' for each file
   - Return list of (filename, blake3_key)

3. **`async def init_and_commit_git(cascade_id: str, files: list[tuple[str, str]], conn, stage: dict, actor_id: str) -> str`**
   - Create directory `workspaces/{cascade_id}/` using `Path.mkdir(parents=True, exist_ok=True)`
   - Write each file to that directory
   - Run `git init` via `asyncio.create_subprocess_exec("git", "init", cwd=workspace_dir)`
   - Run `git add .` via subprocess
   - Run `git commit -m "eclusa: generated code for cascade {cascade_id}"` via subprocess
   - Extract commit hash via `git rev-parse HEAD`
   - INSERT artifact row with type='git_commit', external_ref=commit_hash, external_sys='local_git'
   - INSERT ledger_entry of type 'artifact_created'
   - Return the commit hash string
   - Set GIT_AUTHOR_NAME="eclusa", GIT_AUTHOR_EMAIL="eclusa@system", GIT_COMMITTER_NAME="eclusa", GIT_COMMITTER_EMAIL="eclusa@system" in subprocess env to avoid git config issues

4. **`async def build_and_run_container(cascade_id: str, workspace_dir: str, files: list[tuple[str, str]], conn, stage: dict, actor_id: str) -> str`**
   - Check if "Dockerfile" exists in files list; if not, generate a default one:
     - If any .py file exists: use `FROM python:3.12-slim\nWORKDIR /app\nCOPY . .\nRUN pip install flask 2>/dev/null; true\nCMD ["python", "main.py"]` (or whatever the main .py file is named)
     - Write the Dockerfile to workspace_dir
   - Run `docker build -t eclusa-app-{cascade_id[:8]} {workspace_dir}` via subprocess
   - **Determine app_port for container port mapping:**
     - If a Dockerfile exists (user-provided or generated), parse it for an `EXPOSE` directive: `grep -m1 'EXPOSE' Dockerfile` and extract the port number
     - If the Dockerfile contains Flask code (any .py file imports flask), default app_port=5000
     - Otherwise, default app_port=8080
   - Find a free host port: start from 9000, check availability using a socket bind test
   - Run `docker run -d --name eclusa-ship-{cascade_id[:8]} -p {host_port}:{app_port} eclusa-app-{cascade_id[:8]}` via subprocess
   - Health check: retry up to 10 times with 2s sleep, `httpx.AsyncClient.get(f"http://localhost:{host_port}/")` expecting status 200 or any HTML response
   - INSERT artifact row with type='deployment', external_ref=f"http://localhost:{host_port}", external_sys='docker'
   - INSERT ledger_entry of type 'artifact_created'
   - Return the URL string

5. **`async def dispatch_scc_ship(conn, stage, actor_id) -> None`** — Main entry point.
   - Extract `generated_code` from stage input (injected by propagation from generate stage output)
   - Call parse_generated_code()
   - Call write_files_to_object_store()
   - Call init_and_commit_git()
   - Call build_and_run_container()
   - Resolve stage with output_payload containing: files (list of filenames), blake3_keys, commit_hash, deployment_url
   - Import `_resolve_stage_immediately` from `executor.scc_handlers` (do not copy the function)

Use `SYSTEM_SCHEMA_VERSION = "0002"` (matching existing handlers).
Use `SHIP_TIMEOUT_SECONDS = 120` for Docker build timeout.
Use `HEALTH_CHECK_RETRIES = 10` and `HEALTH_CHECK_INTERVAL = 2` seconds.
