Create `tests/e2e/test_ship_e2e.py` — a pytest E2E test that runs the full 8-stage SCC pipeline with a "simple blog" intent and verifies a running blog is accessible via HTTP.

Follow the existing pattern from `tests/e2e/test_v20_production_e2e.py` but adapted for the ship stage.

The test function `test_simple_blog_intent_produces_running_blog` should:

1. Create a "simple blog" intent via direct SQL INSERT into the intent table:
   - source='api', raw="Build a simple blog with Flask. It should have a homepage that shows a list of blog posts with titles and dates. Use a hardcoded list of posts (no database needed). The blog should serve HTML and be accessible on port 5000."
   - created_by = system actor UUID

2. Create an 8-stage SCC cascade via `create_scc_cascade(intent_id, actor_id, conn)`

3. Run `single_poll_cycle(pool, actor_id)` in a loop (MAX_POLL_CYCLES=120, POLL_INTERVAL=5s) until all stages are terminal (resolved/skipped/failed) or cascade state is completed/failed. Use `asyncio.timeout(600)` (per Phase 24 decision, not pytest.mark.timeout).

4. Assert all 8 stages exist and all are resolved (or skipped — formalize may skip if GHC unavailable).

5. Assert file_created artifacts exist: `SELECT * FROM artifact WHERE cascade_id=$1 AND type='file_created'` — at least 1 row.

6. Assert git_commit artifact exists: exactly 1 row, external_ref is 40-char hex (commit hash), external_sys='local_git'.

7. Assert deployment artifact exists: exactly 1 row, external_ref starts with "http://".

8. HTTP GET the deployment URL via httpx.AsyncClient — assert status 200 and response body contains "<" (HTML).

9. Verify trace chain: JOIN artifact -> stage -> cascade -> intent, assert intent_id matches.

10. Cleanup: `docker rm -f eclusa-ship-{cascade_id[:8]}` via subprocess.

Use fixtures:
- `db_pool`: asyncpg pool from DATABASE_URL env var (default: postgresql://eclusa:eclusa@localhost:5432/eclusa)
- `system_actor`: creates or fetches the system-executor actor

Constants: PIPELINE_TIMEOUT=600, MAX_POLL_CYCLES=120, POLL_INTERVAL=5.
