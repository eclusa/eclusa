   ```python
       {"kind": "response", "content": "I will implement JWT auth with bcrypt password hashing"},

   ctx = prepare_context(history)
   ```
3. Compute context hash via `hash_context(ctx)`.
4. Call `run_judgment_pass("openai:glm-5.1", ctx, "Evaluate whether this implementation plan is sound. Return your verdict.")`.

6. Assert `verdict.decision` is a non-empty string.

10. Clean up: delete judgment_pass, ledger entries, cascade (use cleanup_cascade pattern with trigger bypass).

  <name>Task 3: E2E test — session hot-swap preserves message history (COMP-E2E-03)</name>
  <files>tests/e2e/test_session_hotswap_e2e.py</files>
  <action>
Create `tests/e2e/test_session_hotswap_e2e.py` with pytest E2E tests against the live docker-compose DB.

This test does NOT need to call the live LLM -- it uses pydantic-ai's TestModel for the agent turns, since the requirement is about message history preservation across model swaps, not about LLM output quality.

Use conftest fixtures: `e2e_pool`, `db_conn`, `seed_actor`.

**Test 1: `test_session_pause_resume_preserves_history`**
1. Seed a cascade with 1 narrowing stage.
2. Call `start_work_session(conn, stage_id, intent_id, cascade_id, "model-A", actor_id)`.
3. Create a `pydantic_ai.Agent` with `TestModel()` (no LLM call needed).
4. Call `run_session_turn(conn, session_id, agent, "Hello from model A")` -- this writes message_history to DB.
5. Capture `messages_before = all_messages` from the return.
6. Create a `SnapshotStore(base_dir="/tmp/eclusa/test_snapshots")`.
7. Call `pause_work_session(conn, session_id, snapshot_store)`.
8. Verify DB: `SELECT state, workspace_ref FROM work_session WHERE id = $1` -- state should be 'paused', workspace_ref should be non-null.
9. Call `restored = resume_work_session(conn, session_id, new_model="model-B", snapshot_store=snapshot_store)`.
10. Verify DB: `SELECT state, model, model_swaps FROM work_session WHERE id = $1` -- state='running', model='model-B'.
11. Parse `model_swaps` JSON: assert it's a list with 1 entry, entry has `from='model-A'`, `to='model-B'`.
12. Assert `restored` is a list with the same structure as the serialized messages_before. Compare length at minimum.
13. Call `complete_work_session(conn, session_id, actor_id)`.
14. Clean up cascade + work_session + ledger entries.

**Test 2: `test_session_resume_without_swap_keeps_model`**
1. Same setup: start session with "model-A", run a turn, pause.
2. Call `resume_work_session(conn, session_id, new_model=None, snapshot_store=snapshot_store)`.
3. Verify DB: model is still "model-A", model_swaps is null/empty.
4. Verify restored messages match original.
5. Clean up.

**Test 3: `test_session_message_history_identical_after_swap`**
1. Start session with "model-A", run 2 turns ("Turn 1" and "Turn 2").
2. Read message_history from DB after turn 2.
3. Pause session.
4. Resume with "model-B".
5. Read message_history from DB after resume (should be loaded from snapshot).
6. Run a 3rd turn with a new Agent(TestModel()) -- the resumed session should see all prior messages.
7. Read final message_history from DB.
8. Assert the first N messages (from turns 1+2) are identical between pre-pause and post-resume.
9. Clean up.

**Cleanup pattern:** Same as conftest -- disable immutability trigger, delete ledger_entry WHERE cascade_id, delete work_session WHERE stage_ids overlap, delete stage, cascade, intent. Re-enable trigger in finally block.

**Important:** The `run_session_turn` function takes an agent and user_message. The TestModel will produce synthetic output, but the important thing is that message_history is stored in platform format and survives the pause/resume cycle.
