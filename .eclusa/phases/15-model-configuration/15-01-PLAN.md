    3. Add a `_resolve_model()` helper directly after the removed constants, before `_normalize_stage_input`:
       ```python
       _DEFAULT_SCC_MODEL_FALLBACK = "openai:glm-5.1"

       # Per-stage env var names. Fallback chain: stage-specific -> default -> hardcoded fallback.
       _STAGE_MODEL_ENV: dict[str, str] = {
           "refine": "SCC_MODEL_REFINE",
           "fanout": "SCC_MODEL_FANOUT",
           "match": "SCC_MODEL_MATCH",
           "cohere": "SCC_MODEL_COHERE",
           "formalize": "SCC_MODEL_FORMALIZE",
           "derive": "SCC_MODEL_DERIVE",
           "generate": "SCC_MODEL_GENERATE",
       }

       def _resolve_model(stage_name: str) -> str:
           """Return model identifier for a stage.

           Resolution order:
           1. SCC_MODEL_{STAGE} env var (e.g. SCC_MODEL_REFINE)
           2. SCC_MODEL_DEFAULT env var
           3. _DEFAULT_SCC_MODEL_FALLBACK constant
           """
           default = os.environ.get("SCC_MODEL_DEFAULT", _DEFAULT_SCC_MODEL_FALLBACK)
           stage_env = _STAGE_MODEL_ENV.get(stage_name)
           if stage_env:
               return os.environ.get(stage_env, default)
           return default
       ```

    4. Update every call site that previously used a constant:
       - `dispatch_scc_refine`: replace both `REFINE_MODEL` occurrences with `_resolve_model("refine")`
         — one in `start_work_session(model=...)`, one in `Agent(...)`.
         Both calls are inside the async function body so they call `_resolve_model("refine")` at dispatch time (not module load), which is correct.
       - `dispatch_scc_cohere`: replace both `COHERE_MODEL` occurrences with `_resolve_model("cohere")`.

         cohere_model = _resolve_model("cohere")

       - `handle_derive`: replace both `DEFAULT_SCC_MODEL` occurrences with `_resolve_model("derive")`.
