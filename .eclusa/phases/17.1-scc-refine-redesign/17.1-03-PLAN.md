Add a `cascadeId` derived from messages — scan all assistant messages for a UUID after "cascade_id:" or "cascade created" pattern:

```tsx
const detectedCascadeId = useMemo(() => {
  if (!buildMode) return null
  for (let i = messages.length - 1; i >= 0; i--) {
    const msg = messages[i]
    if (msg.role === 'assistant') {
      // Match UUID pattern after cascade_id: or cascade-id:
      const match = msg.content.match(/cascade[_-]?id[:\s]+([0-9a-f-]{36})/i)
      if (match?.[1]) return match[1]
    }
  }
  return null
}, [messages, buildMode])
```
