**New function signature:**
```python
async def create_scc_cascade_from_refine(
    conn: asyncpg.Connection,
    scope_doc: str,
    actor_id: str,
    *,
    refine_session_id: str | None = None,
    intent_id: str | None = None,
) -> str:
```

**Implementation — inside a single `conn.transaction()`:**

1. If `intent_id` is None, create a new intent with `source='chat'`, `raw=scope_doc[:500]`, `created_by=actor_id`. Otherwise use the provided intent_id (caller already created it during bootstrap).

2. Create cascade:
   - `shape = {"mode": "build", "scc_template": "v2", "refine_session_id": refine_session_id or ""}`
   - `narrative = scope_doc[:200]`
   - `state = 'active'`

3. Create 6 stages in dependency order (NO refine stage — that was the conversation):
   - `fanout`: depends_on=[], input=`{"scc_stage": "intent_validation_fanout", "scope_doc": scope_doc, "refine_session_id": refine_session_id or ""}`
   - `match`: depends_on=[fanout_id], input=`{"scc_stage": "match"}`
   - `cohere`: depends_on=[match_id], input=`{"scc_stage": "cohere"}`
   - `formalize`: depends_on=[cohere_id], input=`{"scc_stage": "formalize"}`
   - `derive`: depends_on=[formalize_id], input=`{"scc_stage": "derive"}`
   - `generate`: depends_on=[derive_id], input=`{"scc_stage": "generate"}`

4. Return `cascade_id`.

Note: the fanout stage receives `scope_doc` directly as its input (not a `refine_stage_id` pointing to a separate DB row, since Refine happened as a chat session). The existing `handle_intent_validation_fanout` in `scc_handlers.py` reads `scope_doc` from `stage_input` if `refine_stage_id` is absent — verify this handles the `scope_doc` key gracefully. If `handle_intent_validation_fanout` does NOT have a `scope_doc` fallback, add one (check `_stage_input_value(stage_input, "scope_doc", default=None)` path in that handler — the fix is just one `_stage_input_value` call addition if missing).

Also update `__all__` (or add it if not present): `["create_scc_cascade", "create_scc_cascade_from_refine"]`

**New build-mode branch logic:**

```python
if body.mode == "build":
    # Build mode: run the Refine agent conversation with tools.
    # The agent decides when to call create_scc_cascade.
    # Same SSE streaming as chat mode — frontend uses the existing path.
    if session_id is None:
        async with pool.acquire() as conn:
            actor_id = await ensure_actor(conn, jwt_identity)
            created = await create_build_chat_cascade(
                conn, actor_id, user_prompt, model_config=body.scc_model_config
            )
        session_id = UUID(created["session_id"])
        session_model = body.model
    else:
        session_row = await _load_session(pool, session_id)
        if not history and session_row["message_history"]:
            raw_history = session_row["message_history"]
            if isinstance(raw_history, str):
                raw_history = json.loads(raw_history)
            history = deserialize_history(raw_history)
        if session_model is None:
            session_model = session_row["model"]

    effective_model = session_model or DEFAULT_CHAT_MODEL
    async with pool.acquire() as conn:
        await conn.execute(
            "UPDATE work_session SET model = $1 WHERE id = $2::uuid",
            effective_model, session_id,
        )
    
    # Acquire a long-lived connection for the RefineContext (tools need DB access).
    # The agent streams; we hold the connection open for the duration of the stream.
    
    async def build_event_stream():
        try:
            async with pool.acquire() as agent_conn:
                actor_id = await ensure_actor(agent_conn, jwt_identity)
                agent = build_refine_agent(effective_model)
                ctx = RefineContext(conn=agent_conn, actor_id=actor_id)
                async with agent.run_stream(
                    user_prompt,
                    message_history=history,
                    deps=ctx,
                ) as result:
                    async for token in result.stream_text(delta=True, debounce_by=None):
                        if token:
                            yield _stream_chunk("0", token)

                    all_messages = result.all_messages()
                    history_json = serialize_history(all_messages)
                    async with pool.acquire() as save_conn:
                        await save_conn.execute(
                            """
                            UPDATE work_session
                            SET message_history = $1::jsonb
                            WHERE id = $2::uuid
                            """,
                            json.dumps(history_json),
                            session_id,
                        )

                    finish_reason = result.response.finish_reason or "stop"
                    yield _stream_chunk(
                        "d",
                        {
                            "finishReason": finish_reason,
                            "sessionId": str(session_id),
                            "mode": "build",
                        },
                    )
        except Exception as exc:
            logger.exception("build stream failed for session %s", session_id)
            yield _stream_chunk(
                "d",
                {
                    "finishReason": "error",
                    "error": str(exc),
                    "sessionId": str(session_id),
                },
            )

    return StreamingResponse(
        build_event_stream(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "X-Vercel-AI-UI-Message-Stream": "v1",
            "X-Eclusa-Session-Id": str(session_id),
            "X-Eclusa-Mode": "build",
        },
    )
```
