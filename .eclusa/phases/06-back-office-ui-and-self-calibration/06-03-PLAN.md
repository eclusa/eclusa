- GET /metrics: for each SQL file, execute `conn.fetchrow(sql)` and extract the first numeric column; if row is None or value is None, return null. Return MetricsResponse Pydantic model with all 8 fields as `float | None`.
- Requires verify_token dependency (per D-13)

Create `adapters/web/api/ws.py`:
- FastAPI WebSocket router (note: WebSocket routes cannot use Depends for auth in standard FastAPI — accept query param `token` for auth validation instead)
- `/ws/sessions/{session_id}` endpoint:
  1. Accept the WebSocket connection
  2. Verify `token` query param via jwt.decode (same logic as verify_token)
  3. On invalid token: send {"error": "unauthorized"} then close
  4. On connect: fetch all existing artifact rows for session ordered by created_at, send each as JSON
  5. Poll loop every 2s: fetch artifacts WHERE created_at > last_sent_at, send new ones; break on disconnect
- Use `asyncio.sleep(2)` between polls; wrap in try/except WebSocketDisconnect
