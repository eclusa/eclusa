  <behavior>

    - GET /api/cascades/{id} returns cascade detail + list of its stages (id, type, state, created_at)
    - GET /api/gates returns all gate stages (type='gate') filterable by ?state=blocked; each row includes id, cascade_id, state, input (jsonb), created_at, model_recommendation (nullable string from input jsonb)
    - Both endpoints require JWT Bearer auth (Depends(verify_token))
    - Missing cascade id returns 404
  </behavior>
  <action>
Create `adapters/web/api/cascades.py`:
- Pydantic response models: `StageStatus(id, type, state, created_at)`, `CascadeItem(id, title, state, created_at, stage_count, blocked_stage_count)`, `CascadeDetail(id, title, state, created_at, stages: list[StageStatus])`
- GET /cascades — asyncpg query:
  ```sql
  SELECT c.id, c.title, c.state, c.created_at,
    COUNT(s.id) AS stage_count,
    COUNT(s.id) FILTER (WHERE s.state = 'blocked') AS blocked_stage_count
  FROM cascade c LEFT JOIN stage s ON s.cascade_id = c.id
  WHERE c.state = 'active'
  GROUP BY c.id ORDER BY c.created_at DESC
  ```
- GET /cascades/{cascade_id} — fetch cascade row + all stage rows for that cascade; 404 if not found
- pool via `request.app.state.pool`

- Extract model_recommendation from input jsonb field `input->>'model_recommendation'` (nullable)

Tests: seed cascade+stage rows in test DB via asyncpg, verify response shapes. Use httpx.AsyncClient + ASGITransport. Pass a valid JWT via Authorization header.
