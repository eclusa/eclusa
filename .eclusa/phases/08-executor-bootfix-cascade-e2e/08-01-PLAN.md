<objective>
Fix the three bugs that prevent the executor container from starting and staying alive inside docker-compose.

Purpose: The executor currently crashes on startup with `OSError: Multiple exceptions: [Errno 111] Connect call failed ('::1', 5432)`. The root causes are: (1) the ACTOR_ID env var is the string "system-executor" but all SQL casts it to `$1::uuid` causing an immediate failure, (2) the executor needs the actor UUID, not the identity string, and (3) the executor service lacks `restart: unless-stopped`.

Output: A running executor container that connects to `db:5432`, resolves the system-executor actor UUID, and enters the poll loop with heartbeat logging.
</objective>

```python
async def ensure_actor(conn, identity, actor_type="human") -> str:
    """Return UUID for an actor with the given identity, creating one if needed."""
    row = await conn.fetchrow("SELECT id FROM actor WHERE identity = $1", identity)
    if row is not None:
        return str(row["id"])
    actor_id = str(uuid.uuid4())
    await conn.execute("INSERT INTO actor ...", actor_id, actor_type, identity, ...)
    return actor_id
```
