Constants:
```python
API_BASE = "http://localhost:8000"
E2E_DSN = "postgresql://eclusa:eclusa@localhost:5432/eclusa"
POLL_INTERVAL_S = 5          # seconds between /stages polls
STAGE_TIMEOUT_S = 300        # 5 minutes total
TERMINAL_STATES = {"resolved", "failed", "skipped"}
```

Helper `_register(client, email, name, password)` — POST /api/auth/register, raise on non-200, return access_token string. Pattern from test_v20_production_e2e.py.

- Mark: `@pytest.mark.asyncio` and `@pytest.mark.timeout(360)` (6 minute pytest-timeout)
- Mark: `pytestmark = pytest.mark.asyncio` at module level

Step 1 — Register:
```python
email = _unique_email()
async with httpx.AsyncClient(base_url=API_BASE, timeout=30) as client:
    token = await _register(client, email, name="Blog Dogfood")
headers = {"Authorization": f"Bearer {token}"}
```

Step 2 — Create cascade via POST /api/scc/create with intent_text = "I want a simple blog where I can write posts and people can read them". Assert 200, extract cascade_id and intent_id.

Step 3 — Poll GET /api/cascades/{cascade_id}/stages every POLL_INTERVAL_S seconds:
```python
deadline = time.monotonic() + STAGE_TIMEOUT_S
all_resolved = False
last_stages = []
while time.monotonic() < deadline:
    await asyncio.sleep(POLL_INTERVAL_S)
    resp = await client.get(f"/api/cascades/{cascade_id}/stages", headers=headers, timeout=15)
    assert resp.status_code == 200
    stages = resp.json()
    last_stages = stages
    not_terminal = [s for s in stages if s["state"] not in TERMINAL_STATES]
    if not not_terminal:
        all_resolved = True
        break
```

After loop, if not all_resolved: build a diagnostic string showing each stage's scc_stage and state, then `pytest.fail(f"SCC pipeline did not complete within {STAGE_TIMEOUT_S}s. Stage states:\n{diagnostic}")`.

Step 4 — Verify no stage failed catastrophically (all terminal, at least 5 resolved):
```python
resolved_stages = [s for s in last_stages if s["state"] == "resolved"]
failed_stages = [s for s in last_stages if s["state"] == "failed"]
# Formalize may fail due to GHC issues — tolerate up to 1 failure if it's formalize
if failed_stages:
    failed_names = [s.get("scc_stage") for s in failed_stages]
    non_formalize_failures = [n for n in failed_names if n != "formalize"]
    assert not non_formalize_failures, f"Non-formalize stages failed: {non_formalize_failures}"
assert len(resolved_stages) >= 5, f"Expected at least 5 resolved stages, got {len(resolved_stages)}"
```

Step 5 — Read Generate stage output via GET /api/cascades/{cascade_id}/stages/{generate_stage_id}/output:
```python
generate_stage = next((s for s in last_stages if s.get("scc_stage") == "generate"), None)
if generate_stage and generate_stage["state"] == "resolved":
    out_resp = await client.get(
        f"/api/cascades/{cascade_id}/stages/{generate_stage['id']}/output",
        headers=headers, timeout=15
    )
    assert out_resp.status_code == 200
    out_body = out_resp.json()
    # Output must exist and contain code-like content
    output = out_body.get("output")
    assert output is not None, "Generate stage output is None"
    output_str = json.dumps(output) if isinstance(output, (dict, list)) else str(output)
    assert len(output_str) > 50, f"Generate output too short: {output_str!r}"
    # Must not be a raw error message starting with "Error" or "Exception"
    assert not output_str.strip().startswith(("Error", "Exception", "Traceback")), \
        f"Generate output looks like an error: {output_str[:200]}"
```

Step 6 — Seed artifact and verify trace chain:
```python
# Find the generate stage_id (or fall back to refine if generate not resolved)
trace_stage = generate_stage or last_stages[0]
stage_id = trace_stage["id"]

# Seed a work_session and artifact so the trace chain query has data
conn = await asyncpg.connect(E2E_DSN)
try:
    session_id = str(uuid.uuid4())
    artifact_id = str(uuid.uuid4())
    await conn.execute(
        "INSERT INTO work_session (id, stage_ids, harness_type, model, state, message_history, cost) "
        "VALUES ($1::uuid, ARRAY[$2::uuid], 'native', 'dogfood-test', 'completed', '[]', '{}')",
        session_id, stage_id,
    )
    await conn.execute(
        "INSERT INTO artifact (id, intent_id, cascade_id, stage_id, session_id, type, payload) "
        "VALUES ($1::uuid, $2::uuid, $3::uuid, $4::uuid, $5::uuid, 'api_response', $6::jsonb)",
        artifact_id, intent_id, cascade_id, stage_id, session_id,
        json.dumps({"dogfood": True, "pipeline": "scc_blog"}),
    )

    trace_resp = await client.get(f"/api/trace/{artifact_id}", headers=headers, timeout=15)
    assert trace_resp.status_code == 200, trace_resp.text
    trace = trace_resp.json()
    hop_types = [h["type"] for h in trace["hops"]]
    assert hop_types == ["artifact", "session", "stage", "cascade", "intent"], \
        f"Expected 5 hops, got: {hop_types}"

    cascade_hop = next(h for h in trace["hops"] if h["type"] == "cascade")
    assert cascade_hop["id"] == cascade_id

    intent_hop = next(h for h in trace["hops"] if h["type"] == "intent")
    assert intent_hop["id"] == intent_id
finally:
    # cleanup artifact + session before cascade cleanup
    try:
        await conn.execute("DELETE FROM artifact WHERE id = $1::uuid", artifact_id)
        await conn.execute("DELETE FROM work_session WHERE id = $1::uuid", session_id)
    except Exception:
        pass
    await conn.close()
```
