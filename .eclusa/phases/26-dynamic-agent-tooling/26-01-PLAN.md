**WorkspaceContext dataclass** (the deps_type for workspace agents):
```python
@dataclass
class WorkspaceContext:
    workspace_dir: str           # Absolute path to workspaces/{cascade_id}/
    conn: asyncpg.Connection     # For DB writes (cost tracking, etc.)
    session_id: str              # Work session ID
    cascade_id: str              # Cascade ID
    stage_name: str              # "derive" or "generate"
    upstream_context: dict       # Injected upstream outputs (scope_doc, constraints, test_suite, etc.)
```

**Four workspace tools** (registered on agents via @agent.tool):

1. `write_file(ctx, path: str, content: str) -> str` — Write content to `{workspace_dir}/{path}`. Create parent dirs. Return confirmation with file size. Reject paths with `..` or absolute paths (security).

2. `read_file(ctx, path: str) -> str` — Read file from `{workspace_dir}/{path}`. Return content or error message if not found. Reject `..` and absolute paths.

3. `run_command(ctx, command: str) -> str` — Run a shell command with cwd=workspace_dir using asyncio.create_subprocess_shell. Timeout 60 seconds. Return combined stdout+stderr. CRITICAL: set PATH to include workspace venv if it exists. Capture return code and prepend it to output like `[exit_code=0]\n{output}`.

4. `list_files(ctx, path: str = ".") -> str` — List files in `{workspace_dir}/{path}` recursively. Return tree-like output. Limit depth to 3 levels to avoid overwhelming the agent.

**Two agent builder functions:**

`build_derive_agent(model: str) -> Agent[WorkspaceContext, str]`:
- System prompt includes: "You are a test specification expert working in a real workspace. You have tools to write files, read files, run commands, and list files. Your job is to derive BDD/E2E test scenarios as executable pytest test files."
- System prompt includes: "You will receive upstream context including the scope document, matched sources, coherence analysis, and formalized constraints. Use these to derive comprehensive test scenarios."
- System prompt includes: "Write test files to the workspace using write_file. Run them with run_command to verify they are syntactically valid (pytest --collect-only). Iterate until tests collect cleanly."
- System prompt includes: "Available tools: write_file, read_file, run_command, list_files"
- Register all 4 workspace tools on the agent

`build_generate_agent(model: str) -> Agent[WorkspaceContext, str]`:
- System prompt includes: "You are a code generator working in a real workspace. You have tools to write files, read files, run commands, and list files. Your job is to generate implementation code that passes all derived tests."
- System prompt includes: "You will receive upstream context including the scope document, constraints, and the test suite derived by the previous stage. The test files are already in the workspace."
- System prompt includes: "Write implementation code using write_file. Install dependencies with run_command (pip install). Run the tests with run_command (pytest). Read error output. Fix issues. Iterate until all tests pass."
- System prompt includes: "When building a web application, ensure it can be started with a simple command (e.g., python app.py). Create a requirements.txt for dependencies."
- System prompt includes: "Available tools: write_file, read_file, run_command, list_files"
- Register all 4 workspace tools on the agent

**Path security**: Both write_file and read_file MUST validate that the resolved path is within workspace_dir. Use `Path(workspace_dir, path).resolve()` and check it starts with `Path(workspace_dir).resolve()`. If not, return an error string (do NOT raise — the agent should see the error and adjust).

**Rewrite `handle_derive` in executor/scc_handlers.py:**

Replace the current blind LLM call pattern with:
1. Create workspace dir: `workspaces/{cascade_id}/` using `Path(WORKSPACES_DIR, str(stage["cascade_id"])).mkdir(parents=True, exist_ok=True)` where WORKSPACES_DIR = `os.environ.get("ECLUSA_WORKSPACES_DIR", "./workspaces")`
2. Start work session (keep existing start_work_session call for DB tracking)
3. Build upstream_context dict from stage_input: `{"scope_doc": ..., "haskell_source": ..., "cohere_output": ..., "matched_sources": ...}` — same keys currently extracted
4. Create WorkspaceContext with workspace_dir, conn, session_id, cascade_id, stage_name="derive", upstream_context
5. Build agent via `build_derive_agent(_resolve_model("derive"))`
6. Compose user_message that includes all upstream context (same content as current user_message but tell the agent to use tools)
7. Call `result = await agent.run(user_message, deps=workspace_ctx)` — NOT run_session_turn. This is the key change. agent.run() handles multi-turn tool calling internally.
8. After agent.run() completes, persist cost data to work_session (extract from result.usage())
9. Persist message history to work_session (serialize result.all_messages())
10. Complete work session
11. Resolve stage with output_payload including: test_suite from reading workspace files, workspace_dir, session_id

**Cost tracking after agent.run():** Since we bypass run_session_turn, we need to manually update the work_session cost. Extract usage from `result.usage()` and write to DB:
```python
usage = result.usage()
cost = {
    "tokens_in": usage.input_tokens or 0,
    "tokens_out": usage.output_tokens or 0,
    "api_calls": 1,
    "tool_calls": len([m for m in result.all_messages() if hasattr(m, 'parts') and any(hasattr(p, 'tool_name') for p in getattr(m, 'parts', []))]),
    "wall_time_ms": wall_time_ms,
    "estimated_usd": 0,
}
await conn.execute(
    "UPDATE work_session SET message_history = $1::jsonb, cost = $2::jsonb WHERE id = $3::uuid",
    json.dumps(serialize_history(result.all_messages())),
    json.dumps(cost),
    session_id,
)
```
